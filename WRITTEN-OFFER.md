# Written offer for source code

Angry Owl Labs LLC distributes Owlert OS (flashable images and device update bundles). Parts of Owlert OS are licensed
under the GNU General Public License (GPL) or the GNU Lesser General Public License (LGPL).

**For at least three years after we last distribute each Owlert OS release, we will give any third party who asks a
complete, machine-readable copy of the corresponding source code for every GPL- or LGPL-licensed component of that
release**, including the scripts used to control compilation and installation of those components. We provide it free
of charge, as a download link.

To ask for it, email **support@owlertos.com** with the subject "Owlert OS source request" and the release name (for
example `OHOS_v2.0.1.0-r5`, shown in Settings on your Owlert and on the portal's device page).

This offer covers every release listed in [`releases/README.md`](releases/README.md), including releases distributed
before this repository existed. Where a source archive is already attached to the matching GitHub release, you can
download it directly.
